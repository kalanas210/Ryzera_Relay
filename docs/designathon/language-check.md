# Language check: Sinhala and Tamil

Every Sinhala and Tamil string in the Figma file, with the English it stands for and where it appears. A native reader goes down the list and, for any line that doesn't sound like everyday speech, writes the better wording in the last column. Each change then goes into the Figma file and into the step file named in `tools/figma-builder/steps`.

IDs (VEH045, OUT118), people's names and the brand word "Fresh" stay in Latin letters on purpose. Place names are in the script of the screen's language, except in the loader's Tamil frame, where they stay as the dock knows them.
